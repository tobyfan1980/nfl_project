# NFL Game Interval Charts

Use this skill to visualize the days_between_games feature generated by
nfl-previous-game-gap. First prepare deterministic counts with
scripts/summarize_game_intervals.py, then use the visualize skill to render an
interactive D3 bar chart.

## Data Preparation

Pass one or more yyyy_game_intervals.csv files. The script validates the
days_between_games column, combines the selected seasons, and emits JSON with
the calendar-day counts.

    python3 <skill-dir>/scripts/summarize_game_intervals.py \
      --input-files /path/to/nfl_project/dev_data/metrics/2022_game_intervals.csv \
                    /path/to/nfl_project/dev_data/metrics/2023_game_intervals.csv \
                    /path/to/nfl_project/dev_data/metrics/2024_game_intervals.csv \
                    /path/to/nfl_project/dev_data/metrics/2025_game_intervals.csv

Use --output-file to save the JSON for a separate rendering step.

## Rendering

Use a discrete bar chart because calendar-day gaps are integer values. Include
zero-count days between the observed minimum and maximum values so that gaps in
the schedule remain visible. Label the x-axis Days between previous and current
game and the y-axis Team-games.

For a request covering multiple years, state the selected years and pooled row
count in the subtitle. For a single season, use only that season file rather
than filtering the pooled output after aggregation.
