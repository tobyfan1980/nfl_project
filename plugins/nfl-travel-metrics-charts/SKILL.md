# NFL Travel Metrics Charts

Use this skill for charts based on the season files generated by
nfl-travel-timezone. First prepare deterministic chart data with
scripts/summarize_travel_metrics.py, then use the visualize skill to render an
interactive D3 chart.

## Supported Charts

- timezone-transition-distribution: bar chart of
  timezone_transition_hours counts.
- travel-miles-histogram: histogram of travel_miles.
- log-travel-miles-histogram: histogram of ln(1 + travel_miles). Keep
  zero-mile records as a distinct zero bucket; do not discard them because
  log(0) is undefined.
- average-travel-by-team: horizontal bar chart of mean travel_miles by team.

## Data Preparation

Run the summary script against one season file. It validates the required
columns and emits JSON to stdout, or writes it to --output-file.

    python3 <skill-dir>/scripts/summarize_travel_metrics.py \
      --input-file /path/to/nfl_project/dev_data/metrics/2025_travel-timezone.csv \
      --metric average-travel-by-team

Use --bins to choose the number of equal-width histogram bins. The default is
12. The log metric reports zero_count separately from the positive log bins.

## Rendering

Use the visualize skill to generate a responsive D3 HTML visualization from
the prepared JSON. Label axes with the original units and state the season and
row count in the subtitle.

- Use a discrete bar chart for timezone-transition values.
- Use a horizontal sorted bar chart for average travel by team.
- Use a continuous x-axis with equal-width bins for travel histograms.
- Label the log transform exactly as ln(1 + travel miles).

Do not treat travel_miles as driving distance: it is the deterministic
great-circle route feature generated by nfl-travel-timezone.
