# NFL Opponent Strength Charts

Use this skill to visualize the feature generated by `nfl-opponent-strength`.
First prepare deterministic histogram data with
`scripts/summarize_opponent_strength.py`, then use the `visualize` skill to
render a responsive D3 chart.

## Data Preparation

Pass one or more `yyyy_opp_strength.csv` files. The script validates
`opponent_strength_average_win_rate`, groups records by season, and emits JSON
with fixed-domain histogram bins, mean, and population standard deviation.

```bash
python3 <skill-dir>/scripts/summarize_opponent_strength.py \
  --input-files /path/to/nfl_project/dev_data/metrics/2022_opp_strength.csv \
                /path/to/nfl_project/dev_data/metrics/2023_opp_strength.csv \
                /path/to/nfl_project/dev_data/metrics/2024_opp_strength.csv \
                /path/to/nfl_project/dev_data/metrics/2025_opp_strength.csv
```

Use `--output-file` to save the JSON. The default 20 bins cover 0–1 in
increments of 0.05; change the resolution with `--bins` only when requested.

## Rendering

- For multiple seasons, use shared-scale histogram facets rather than pooling the records.
- Label the x-axis `Average opponent win rate` and y-axis `Team-game rows`.
- Show each season's row count, mean, and population SD in its heading.
- Draw the mean as a vertical line and mean ±1 SD as a subtle shaded band.
- Keep the x-domain fixed at 0–1 and use a shared y-domain across facets.
- Include bin ranges and counts in accessible tooltips.
