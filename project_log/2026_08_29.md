# Project Log - August 29, 2026

## NFL Analysis Skills

Created and organized reusable project-local skills under `plugins/` for deriving team and schedule features from the repository's `yyyy_games.csv` files.

### Skill Location

- Moved `nfl-previous-five-win-rate` from the user-level Codex skill directory into `plugins/nfl-previous-five-win-rate`.
- All skills include a `SKILL.md`, UI metadata in `agents/openai.yaml`, and a standard-library Python CLI in `scripts/`.

### Previous Five Win Rate

- Added `plugins/nfl-previous-five-win-rate`.
- Inputs: game CSV, target date, and team name.
- Selects the five most recent completed games strictly before the target date.
- Reports the selected games, record, and win rate; ties count as half a win.

### Previous Game Gap

- Added `plugins/nfl-previous-game-gap`.
- Inputs: game CSV, team name, and next-game date.
- Finds the latest completed game before the supplied next-game date.
- Reports the prior game and the calendar-day interval to the next game date.

### Travel and Timezone

- Added `plugins/nfl-travel-timezone`.
- Inputs: game CSV, team name, next-game venue (`home` or `away`), and next-game city.
- Applies the requested home/away routing rules, including the away-to-away home-detour threshold.
- Calculates deterministic great-circle miles and daylight-saving-aware IANA timezone changes.
- Added an editable stadium and neutral-site catalog at `plugins/nfl-travel-timezone/references/nfl_stadium_locations.json`.
- Neutral-site games in `2025_games.csv` use date-and-matchup location overrides because the CSV ZIP column represents the nominal home stadium.

### Opponent Strength

- Added `plugins/nfl-opponent-strength`.
- Inputs: game CSV, team name, and current-date cutoff.
- Selects the team's five latest completed opponents before the cutoff date.
- Calculates each opponent's rate as its wins in its prior five completed games divided by five, then averages those rates.
- Uses the same cutoff date for all opponent records to avoid look-ahead.
